# TaskFlow Pro ⚡

> **Next-Gen Work OS** — Ultra-responsive, ClickUp 3.0 & Linear-inspired project management web app with Deep Teal & Obsidian Dark aesthetics, 4-tier hierarchy, real-time subtask rollup, Gantt timelines, Pomodoro time tracking, and interactive Kanban boards.

---

## ✨ Features

- **🏢 4-Tier Organization Hierarchy**: Workspace ➔ Spaces ➔ Folders & Lists ➔ Tasks & Nested Subtasks.
- **🎨 5-Stage Custom Workflow**:
  - `Not Started` (`#64748B` Slate Gray)
  - `Planning` (`#0284C7` Ocean Blue)
  - `In Progress` (`#0D9488` Dark Teal with pulse dot)
  - `Done` (`#059669` Deep Emerald Green) — triggers celebratory confetti!
  - `Closed` (`#475569` Muted Zinc with strikethrough)
- **📊 5 Interactive Views**:
  - **Kanban Board**: Drag-and-drop columns with 2-degree tilt effect.
  - **List View**: Grouped collapsible tables with inline title & status editing.
  - **Gantt / Timeline**: Horizontal schedule bars spanning Start Date to Due Date.
  - **Calendar View**: Monthly calendar grid mapping tasks and overdue markers.
  - **Analytics Dashboard**: Real-time completion rate, risk matrix, logged hours, and member workload capacity.
- **⚡ Slide-Over Task Detail Drawer**: 2-column layout with rich descriptions, subtask auto-rollup progress bar, checklists, file attachments, and activity logs.
- **⏱️ Live Stopwatch & Pomodoro Timer (25m)**: Track deep work sessions directly into task logged hours.
- **⌨️ Command Palette (`Cmd/Ctrl + K`)**: Keyboard-first spotlight search across tasks, status changes, theme toggling, and instant view navigation.
- **📦 Floating Bulk Action Bar**: Batch select tasks to update status, assign members, or delete in one click.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/zhsaikot/taskflowzhs.git
cd taskflowzhs

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
